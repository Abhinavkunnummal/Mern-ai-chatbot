# MERN AI Chatbot

An AI chatbot built using the MERN stack.

## Tech Stack

- React (Vite)
- Node.js
- Express
- Groq AI API

## Features

- MERN developer assistant
- ChatGPT style UI
- Typing indicator
- Real-time AI responses

## Setup

Backend

npm install
node server.js

Frontend

npm install
npm run dev
